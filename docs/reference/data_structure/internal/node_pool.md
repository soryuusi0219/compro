# internal/node_pool

[索引](../../README.md) / [実装](../../../../library/data_structure/internal/node_pool.hpp)

## 機能・前提条件

ポインタ木と永続構造の内部用ノードプール。dequeにノードをブロック単位で確保し、追加時にも既存ノードのアドレスを維持します。ノードごとの参照カウント・deleteは行わず、領域全体の終了時にまとめて破棄します。Nodeに非自明なデストラクタがある場合も呼び出されます。

コピー禁止・move可能。moveによりノードの所有権と所有元IDを移し、移動元からの追加は新しい領域で行います。Rootは所有権を持たないため、元領域の破棄・置換後は無効です。単一管理領域への並行更新は想定しません。デバッグ用IDの発行も単一スレッドで行ってください。

## インターフェース

`internal::NodePool<Node>` のcreate(args...)でNodeを構築し、size()で確保数を取得します。root(pointer)とget(root)は各データ構造の実装専用です。利用者向けにノードポインタを取り出すAPIは公開しません。

`internal::NodeRoot<Node>` は外部から内部ポインタを操作できない値型です。既定構築は未設定の空版を表し、各管理領域で使用できます。領域IDを持つ版は同じ領域のみで有効で、デバッグ時に検査します。空版以外を既定構築する必要がある構造（DSUなど）は、各構造のempty_root()を使用してください。等値比較はハンドルの一致であり、内容の等価性ではありません。

## 計算量

createは償却 O(1)、size/root/getとmove構築は O(1)。Kノードに O(K) 空間。領域破棄はNodeの破棄時間を含め O(K)、move代入は置換前の領域の破棄時間を要します。デバッグ版のRootはポインタと所有元ID、NDEBUG版はポインタのみを格納します。

## 依存関係

標準ライブラリのみ。

## 性能比較

[ベンチマーク](../../../../tools/benchmarks/pointer_structures.cpp)をg++、`-std=c++20 -O2 -DNDEBUG`で実行しました。
変更前はコミット `916fe91` の実装です。乱数はmt19937、seed=12345。各条件3回の操作時間の中央値と最大RSSです。時間は管理領域の破棄前までを計測します。

| 入力 | 変更前の時間 / RSS | 変更後の時間 / RSS |
| --- | --- | --- |
| 動的セグ木：領域2³⁰、ランダムset 20万回＋prod 20万回 | 0.153秒 / 13,076 KiB | 0.146秒 / 11,976 KiB |
| 永続遅延セグ木：領域2²⁰、区間加算1万回＋prod 10万回 | 0.332秒 / 265,088 KiB | 0.087秒 / 49,588 KiB |

両版で集約結果のチェックサムは一致しました。前者でプール化による時間・メモリの悪化がなく、
後者では問い合わせの経路コピーをなくす効果が大きいため、この実装を採用しています。
汎用のdefault_prodは既存のstd::functionを維持し、分岐数や整数IDへの変更は今回行っていません。
