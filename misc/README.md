# Miscellaneous

ライブラリ管理に直接含まれないコードを保存します。

- `solutions/`: 問題固有の解法コード
- `experiments/`: 未完成の実装やアルゴリズムの試作
- `templates/`: 競技やストレステスト用のテンプレート
- `library_drivers/`: ライブラリから分離した旧 `main` 関数
- `legacy/`: verify へ移行済みの旧解答や、旧ディレクトリ構成を前提とするスクリプト

`legacy/` のスクリプトと重複した旧 ACL ヘッダは、現時点では保存用です。
再利用可能な実装として完成したものは `library/` へ移し、対応する検証コードは `verify/` に追加します。
