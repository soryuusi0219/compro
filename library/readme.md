# Library

問題に依存せず再利用できる、完成済みの自作ライブラリを置きます。

- `data_structure/`: データ構造とオフラインクエリ
- `graph/`: 一般グラフのアルゴリズム
- `math/`: 数論、畳み込み、多項式、線形代数
- `string/`: 文字列アルゴリズム
- `tree/`: 木に特化したアルゴリズム
- `utility/`: 複数分野で使う補助アルゴリズム

ライブラリの拡張子は `.hpp` に統一し、可能なら単体でインクルードできる形で追加します。
各ヘッダーの先頭行には、そのファイルの GitHub URL を `//` コメントで記載します。
この規約は `make check` で検査され、URLコメントは展開後のコードにも保持されます。
公開する型と関数は `soryuusi` 名前空間に置きます。
問題の入出力や `main` 関数を含むコードは `misc/solutions/` または `verify/` に置きます。
